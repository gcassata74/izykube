Getting started

Up and running in minutes

One command starts the full stack: MongoDB, k3s, Ollama, and IzyKube.

1

Clone the repository

git clone https://github.com/izylife/izykube.git
cd izykube
2

Start the full stack

docker compose up

Starts MongoDB, a private Docker registry, k3s, Ollama, and IzyKube at http://localhost:8090. The first run builds the image (Maven + Angular).

3

Install cluster addons

export KUBECONFIG=$(docker volume inspect izykube_kubeconfig \
  --format '{{.Mountpoint}}')/config
make install-cluster-addons

Installs OLM, cert-manager, Istio + gateway, Prometheus, and Grafana into k3s.

4

Open the UI

Visit http://localhost:8090 to start modeling your Kubernetes architecture.
