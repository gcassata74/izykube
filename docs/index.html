Self-hosted setup

Review the prerequisites before starting

IzyKube is self-hosted. Terraform provisions the local k3s cluster and Docker network. The current Compose setup also expects a generated Kubernetes kubeconfig and pre-existing external MongoDB and Ollama data volumes. A clean Docker host cannot start the stack with docker compose up alone. The README documents the repository's development setup and these limitations.

FAQ

Common questions before adoption

Is IzyKube a hosted SaaS?

No. IzyKube is open-source and self-hostable. You can run it locally or in your own infrastructure.

Does it replace kubectl or Helm?

No. IzyKube complements kubectl, Helm, Git review, and your existing deployment tools by modeling supported resources and generating artifacts.

Who is it for?

IzyKube is aimed first at small platform teams and Kubernetes consultancies that need a visual way to design supported namespace resources and produce reviewable artifacts.
